# Projector 0.3.0

Release Date: 2026-10-03

## What's Changed

### `deps --outdated` (`src/outdated.rs`)

- New `--outdated` flag on `projector deps` checks each project for newer
  upstream versions. Projector never talks to a registry itself: it delegates
  to each ecosystem's *own* tool — `cargo-outdated`, `npm outdated`,
  `go list -m -u`, `pip list --outdated` — so crates.io / npm / PyPI /
  module-proxy clients are not reimplemented here.
- **Offline by default.** Nothing shells out unless the flag is passed, so
  `deps` without `--outdated` never reaches the network.
- A missing tool is not an error: it degrades to `⚠ tool not available — <install
  hint>` and the result is marked partial, so an empty report is never mistaken
  for "everything is current".
- Per-ecosystem pure parsers (`parse_cargo_outdated`, `parse_npm_outdated`,
  `parse_go_outdated`, `parse_pip_outdated`) are unit-testable offline; npm's
  "not installed" case and go's bracketed-upgrade lines are handled explicitly.
- Terminal output renders an `Outdated check — N project(s) queried` section;
  JSON output gains an `outdated` block (`projects_checked`, `outdated`,
  `outdated_count`, `tools_missing`, `failures`), `null` when the flag is off.

### Markdown output expansion (`src/markdown.rs`, `src/export_template.rs`)

- `projector brief -f md` renders the daily brief as a Markdown digest (was
  JSON-or-terminal only), for pasting into notes/READMEs.
- New `projector export markdown` subcommand renders the same dashboard that
  `export html` produces as a Markdown document (`-o` writes to a file,
  default stdout).
- New shared `src/markdown.rs` GitHub-flavoured table builder used by `report`,
  `brief`, and `export markdown`; cells escape `|` and newlines so project names
  and paths never break the table.

### Integration tests

- `tests/cli.rs` grows from 5 to 12 end-to-end tests, all running the real
  binary against an isolated temp `HOME`:
  tag lifecycle, HTML/Markdown export, shell completion for bash/zsh/fish,
  `snapshot prune --keep/--dry-run`, `stats -f json`, `brief -f md`, and
  `deps --outdated` being offline without the flag.

### Docs

- `USAGE.md` documents `deps --outdated`, `brief -f md`, and `export markdown`;
  version bumped to 0.3.0.
- `README.md` quick-start gains examples for `--outdated`, Markdown export, and
  `brief -f md`; command table updated.
- `AGENTS.md` architecture list gains `outdated` and `markdown` modules.

## CLI usage

```bash
projector deps --outdated                    # check all snapshot projects for newer versions
projector deps --shared --outdated -f json   # shared deps + outdated, as JSON
projector brief -f md                        # Markdown daily brief
projector export markdown [-o dash.md]       # Markdown dashboard
```
